# ChrisLab DNS 0.2.0

Version 0.2.0 extends ChrisLab DNS from a single-server zone editor into a DNS platform foundation.

## Added

- Primary and secondary zone configuration.
- Secondary `primaries` configuration with multiple upstream DNS servers.
- Primary `allow-transfer` and `also-notify` policy management.
- TSIG key generation, encrypted-at-rest storage, assignment and rotation.
- DNS server registry with TCP/53 reachability checks.
- LDAP `memberOf` group-to-role mapping for Administrator, Operator and Read Only.
- TOTP two-factor authentication for Web UI sessions with one-time recovery codes.
- Zone revision history and rollback with monotonic SOA serial/version handling.
- Dedicated **DNS Platform** and **Security / 2FA** Web UI pages.
- REST API resources for DNS servers, TSIG keys and zone revisions.
- Additive database migrations for upgrades from 0.1.x.

## Authentication defaults

Fresh installs use the local application account:

- username: `admin`
- password: `admin`

Change these credentials after the first login. Authentication can then be switched to Linux/PAM or LDAP in Settings. TOTP can be enabled independently from the selected primary authentication provider.

## Upgrade

```bash
cd /opt/HomeLAB-DNS
git pull
sudo ./update.sh
```

The updater runs the additive schema migration before restarting the Web application.
